# Part 3 — Smart City Traffic Intelligence

An educational, single-corridor traffic analytics project using the supplied Metro Interstate Traffic Volume CSV. **No real accident dataset was used. Classification predicts a documented proxy label, not actual accident likelihood.**

Part 3 reuses those preparation ideas but recomputes imputation, encoding/scaling and target quartiles on training data only. It reads the original CSV to avoid leakage from full-dataset Part 2 transformations.

## Data and features

- 48,204 raw rows; 17 exact duplicates removed; 48,187 modelling records.
- 40,575 unique timestamps. Chronological 70/15/15 unique-hour split yields 33,497 / 7,274 / 7,416 rows.
- Training ends 2017-05-10 04:00; validation ends 2018-01-19 14:00; test begins 2018-01-19 15:00.
- Train-only monthly medians, with train-wide fallback, repair invalid weather values. Different weather rows at the same timestamp remain, so metrics are record-weighted.
- Inputs: `hour`, `day_of_week`, `month`, `is_weekend`, `is_holiday`, `hour_sin`, `hour_cos`, `dow_sin`, `dow_cos`, `temp_c`, `rain_1h`, `snow_1h`, `clouds_all`, `is_raining`, `is_snowing`, `is_low_visibility`, `weather_main`.
- Weekday encoding: Monday=0. Cycles use 2π × hour/24 and 2π × weekday/7. Temperature is Kelvin minus 273.15.
- Low visibility is inferred from mist/fog/haze/smoke, not measured visibility. Holiday markers are propagated to their recorded date within each partition; unmarked days may be missed.
- The saved model pipeline standardizes numeric features and one-hot encodes weather using training-only fitted parameters.

## Proxy definition

Training quartiles: Q1=1160, Q2=3331, Q3=4924. Low ≤Q1; Medium >Q1 and ≤Q2; High >Q2 and ≤Q3; Severe >Q3.

`high_risk = High/Severe volume AND (snow/thunderstorm/squall OR low-visibility weather)`.

Traffic volume, congestion category and high_risk are excluded from inputs. Weather still participates in both the input and the label definition, so strong scores partly reflect rule reconstruction. Zero does not mean safe; output scores are not calibrated accident probabilities. Part 1's >5500 definition and Power BI's fixed categories are different from these Part 3 quartile categories.

| MLP (64, 32) | 279.05 | 0.9527 | 41.71 | 281.63 | 0.9433 |

Regression is selected by validation MAE. Classification is selected by validation F1, with ROC AUC as tie-breaker. Random Forest classification test accuracy/precision/recall/F1/ROC AUC: **0.9784 / 0.8621 / 0.9777 / 0.9162 / 0.9954**, using threshold 0.5.

K-means selects k=3 (silhouette 0.2645): mostly weekday daytime, weekend, and weekday night/evening patterns. Rules enumerate time/day/weather combinations with support ≥0.01, confidence ≥0.60 and lift >1. SHAP explains the Random Forest on 200 validation samples, not the MLP itself.

## Recommendation engine

After running preparation and the recommendation cell:

```python
recommend_travel(day_type="Weekday", weather="clear", start_hour=6, end_hour=10, top_n=3)
```

It ranks train-only historical mean traffic for each eligible hour and requires ≥10 observed hours per condition. The hour range includes both endpoints and does not wrap across midnight. The recorded example ranks 10:00 (4472.42), 09:00 (4971.31), then 06:00 (5502.19). Empty matches produce an empty table and a warning. Use the returned `departure_time`, weather, day type and `reason` to present the suggestion. Check for an empty result before plotting or accessing its first row.

This is historical travel timing for a single corridor, not routing, live forecasting or guaranteed travel-time savings. Profiles are saved in `reports/travel_timing_profiles.csv`. The function implementation is in the notebook.

## Monitoring, fairness and governance

The MAE alert threshold is 1.25 × validation MAE = 312.30. Actual test MAE 246.60 passes. Adding 1000 to predictions gives 1031.64 and alerts. This synthetic test requires observed labels; it does not establish live drift or implement feature-distribution drift detection.

`reports/fairness_group_metrics.csv` audits 17 condition groups. Weekend, fog, snow and evening errors deserve review. Six late-evening positive proxy cases were all missed. Smoke has only two records. Undefined metrics mean the necessary class denominator is absent. No demographic fairness claim is possible from these data. See the accompanying report for sampling risks, human oversight, future controls and resource trade-offs.

## Logging

The submission notebook and API use `logging.getLogger(__name__)`. The notebook entry cell configures console and `part3.log`; standalone `app.py` configures console and `api.log`. When imported by notebook tests, the API inherits notebook logging. Format includes timestamp, level, module name and message.
